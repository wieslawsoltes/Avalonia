# Design 06: default single-run line metrics and adaptive probing

The remaining line-metrics shortcut reuses the original formatter's computed value, not an approximation. Each admitted immutable shaping snapshot may retain one metrics/bounds snapshot keyed by a weak renderer identity. Eligibility requires a fresh, unexposed single ShapedTextRun, unchanged glyph-holder generation, bidi level zero, exact built-in run properties, the same typeface/size for default and actual runs, default left/start LTR non-wrapping paragraph settings, and a backend explicitly opting into immutable metrics. Initially only the internal Skia backend opts in. Overflow is recomputed against the current paragraph width. Other paragraphs, exposed mutable GlyphRuns, custom renderers, splits, mutations and typography settings keep the original path.

The shared cache contains values, not TextLine, font, mutable buffer, renderer ownership or live GlyphRun objects. Existing pooled glyph-holder generations invalidate metrics when an alias changes glyph data. Typeface disposal is still checked on a hit. Paragraph formatting, bidi processing, source consumption, trimming and hit testing are not removed. Drawing may lazily create a glyph run later, using the independently implemented shared native geometry/blob cache.

Shaping also adapts to one-pass workloads. After 64 unsuccessful probes without an admission/hit, it probes once per 64 calls before creating/hashing a full key. A hit or admission restores normal probing. Sampling changes only whether work is reused, never the output; cold-to-hot recovery is tested. This specifically targets the measured unique-text CPU overhead rather than merely documenting it.

Tests compare all line metrics and bounds exactly with the original uncached path, verify width-dependent overflow and hit testing, reject non-default paragraphs and exposed glyph runs, and invalidate via buffer aliases. Adaptive probing tests cover cold scans, recovery and exact glyph equality. The one-shot integration workflow validates the exact source edits before committing them on the existing branch; this document is not a passing-test claim until that run succeeds.
