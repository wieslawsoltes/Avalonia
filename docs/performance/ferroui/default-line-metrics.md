# Design 06: default single-run line metrics and adaptive probing

The line-metrics shortcut reuses the original formatter's computed values. Each admitted immutable shaping snapshot may retain one metrics/bounds snapshot keyed by weak renderer identity. Eligibility requires a fresh unexposed single ShapedTextRun, unchanged glyph-holder generation, bidi level zero, exact built-in run properties, matching default/actual typeface and size, default left/start LTR non-wrapping paragraph settings, and a backend explicitly opting into immutable metrics. Initially only the internal Skia backend opts in. Overflow is recomputed against current paragraph width. Other paragraphs, exposed mutable GlyphRuns, custom renderers, splits, mutations and typography settings take the original path.

The context retains values, not TextLine, fonts, mutable buffers, renderer ownership or live GlyphRuns. Existing shared holder generations invalidate metrics when an alias changes glyphs. Typeface disposal remains checked. Paragraph source consumption, bidi processing, trimming, justification and hit testing are not removed. Justification retains its own original recalculation; only ordinary finalization uses the shortcut. Drawing can lazily create a glyph run later through the native geometry/blob cache.

Shaping adapts to unique workloads. After 67 unsuccessful probes without benefit it probes once per 67 calls before constructing/hashing a full key. A hit or admission restores normal probing. The non-power-of-two interval avoids synchronizing with common over-capacity scan sizes. Sampling affects reuse, never output. The first implementation used 64; measurements exposed sampling alignment with a 4,096-string scan and motivated the refinement.

`DefaultLineMetricsCacheTests` compares every line metric and both bounds exactly with the uncached original, checks overflow at different widths and hit testing, rejects non-default paragraphs/exposed runs, and invalidates through aliases. It also verifies that a real cache hit avoids eager GlyphRun construction. `AdaptiveShapingProbeTests` covers cold scans, recovery and exact glyph equality. The real counter workload independently requires nonzero default-metrics hits; a direct unit-test-only fast path would not satisfy it.

The integrated implementation was tested before commit on the same branch; temporary staging scripts and files were removed. ShapedBuffer's metrics token adds 16 bytes on the measured x64 runtime. That footprint is explicit: compare full layout savings and cold-run costs, not just cache-hit timing. Exact revision results belong in the validation report.
