# Designs 06/07: cross-layout native glyph geometry and blob reuse

`GlyphRunImpl` now leases immutable `SharedGlyphRunData`. Repeated short glyph sequences can reuse glyph indices, positioned glyph arrays, relative native bounds and edging/hinting-specific Skia text blobs even when the original layout was disposed and recreated. Baseline origin stays in each wrapper and translates relative bounds independently. Paragraph layout, line breaking, trimming and hit testing remain on the existing formatter; reusing a native run is not equivalent to skipping paragraph formatting.

The key includes backend typeface object identity, exact rendering size and every glyph record. Hashes only locate candidates; all records are compared before a hit. Features, spacing, direction and culture are already reflected in shaped glyph records. Custom list implementations and long runs bypass memoization. Two-touch admission avoids snapshot allocation for ordinary one-off runs. The LRU has hard 128-entry and 128-glyph-per-entry limits, plus a 2 MiB conservative geometry/blob accounting allowance. This is not an exact measurement of Skia's internal native allocations.

Each live wrapper and cached entry owns a reference. Eviction releases only the cache's reference. Shared data keeps at most the 18 effective edging/hinting/baseline font-state blobs; it does not evict individual blobs while any lease exists, because another wrapper may currently be drawing a borrowed blob. Wrapper-local lookup caches borrow these blobs and never dispose them, preserving lock-free warmed lookups. Shared blob creation is serialized. Typeface disposal removes its cache entries. Input buffers are snapshotted, not retained as mutable buffers, and new runs reject disposed backend typefaces.

`SharedGlyphRunTests` checks cross-layout reuse, independent baseline/bounds, exact PNG raster equality with uncached custom-list runs in three edging modes, mutation isolation, option separation and survival of disposal/eviction while another wrapper is alive. `SharedGlyphBlobLifetimeTests` holds a borrowed blob while another wrapper cycles every effective font state, then exercises concurrent wrapper reads. These comparisons supplement, rather than replace, full browser/GPU and platform render-suite validation.
